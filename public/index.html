Project Overview

The Advanced Patient Appointment Scheduling & Pre-Arrival Management System is a full-stack clinical platform designed to streamline outpatient visits, schedule advance appointments, and eliminate double-booking conflicts.

Tech Stack
  • Frontend: HTML5, CSS3, Bootstrap 5.3, Vanilla JavaScript (SPA Architecture)
  • Backend: Node.js, Express.js REST API
  • Database: MySQL 8.x with connection pooling (mysql2/promise)
Database Tables & Relationships
  • patients: Demographics, contact information, emergency contacts
  • doctors: Healthcare providers, medical specialties, active status
  • doctor_schedules: Weekly availability slots and session durations
  • appointments: Patient-doctor bookings with double-booking prevention
  • appointment_status_history: Clinical visit flow audit history
